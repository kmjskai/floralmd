# FloralMD 使用指南

本指南描述当前集成的统一工作区流程。该版本尚未发布；需要人工验收的项目见 [PROGRESS.md](PROGRESS.md)。

## 首次设置 Draft 工作区

首次启动时，选择一个文件夹作为 `FloralMD Drafts` 根目录。FloralMD 会在其中准备：

```text
notes/
notes/assets/images/
drawings/
```

第一次实际同步 SVG 时，FloralMD 才会按需创建 `drawings/exports/`。

可以在设置或菜单中更换默认文件夹。更换后，统一窗口回到新 Draft 工作区；旧文件不会被搬移或删除。

## 新建 Markdown

- 点击工具栏的笔记加号，或使用快速记录入口。
- 新文件自动创建在 Draft 的 `notes/`。
- 直接输入 Markdown；FloralMD 会自动保存，也可以点击保存按钮或按 `Command+S`。
- 选中一段文本时，选区触及的 Markdown 语法会完整显露源码；跨多行列表会逐行显示 `-`、`*`、序号和 task marker，标题与行内标记不会只露出一半，行内代码也不再保留背景、圆角或语义颜色。显露期间保留标题字号/行高、列表缩进和行内代码尺寸，减少选区弹跳；同一视觉行内由这些透明占位造成的小间隙会合并成连续高亮，但空白逻辑行仍不填蓝色，图片预览也不会看起来被文字选区选中。取消选区后自动恢复完整实时预览，复制仍得到原始 Markdown。中文输入法组合文字不会触发这种排版切换。
- 用工具栏在实时编辑与只读预览间切换。实时编辑中正文和标题保持系统主文字色，链接为蓝色，图片引用为柔紫，行内代码为暖棕并保留背景，Markdown 标点为次级灰。左侧 gutter 的 H1–H6 保持中性，围栏代码显示 `CODE`，独立图片或图片画廊行显示 `IMG`；正文句中的内联图片不显示 `IMG`。这些颜色没有单独设置开关，选择文本、搜索命中与失败提示会优先显示。
- “设置 → 编辑 → 打字机模式”默认关闭。开启后，打字机只拦截结构编辑：打字过程中（普通字符、中文输入法）它完全不干预滚动，滚动行为与关闭时完全一致；按回车创建新行、按退格或删除合并行/删除选区时，FloralMD 会把当前视觉行平滑带到编辑区约 47% 高度——页面滚动对齐，光标视觉行回到舒适位置。方向键移动光标时也会把当前行带回舒适位；缩放、窗口大小或内容宽度变化不会让页面自动滚动；文档第一行/最后一行附近的对齐会被滚动边界限制（够不到舒适线）。鼠标点击、拖选或滚轮/触控板滚动会暂停跟随，下一次回车或方向键再恢复。也可以从“编辑”菜单或命令面板切换；该命令不占用快捷键。
- Markdown 有标题时，可以展开大纲并点击标题跳转。

## 浏览与切换资源

左侧工作区侧栏显示普通文件夹和普通文件。Markdown、`.excalidraw`、PNG、JPG、JPEG、GIF、WebP 和 SVG 可在统一编辑区打开；其他文件仍会显示，后续可通过 Quick Look、Finder 和文件操作使用，但不会误交给编辑器。
文件树从标题栏下方的正常系统间距开始，各类中央内容和窗口尺寸使用同一侧栏布局。

隐藏文件、Finder package 和符号链接不会显示；FloralMD 不会跟随符号链接越过已授权工作区。不可读子目录会保留在树中并显示受限状态，不会让整个侧栏消失。

- 点击 Markdown：中央区域显示编辑器或预览。
- 点击 `.excalidraw`：中央区域显示绘图画布。
- 点击 PNG、JPG、JPEG、GIF、WebP 或 SVG：中央区域显示统一的只读图片查看器，不会弹出外部“预览”App。
- 在图片上使用触控板双指滑动或滚轮可以平移；触控板捏合或按住 `Command` 滚动会围绕指针位置缩放；按住图片拖动也可以平移。
- 底部工具条可以缩小、放大、适应窗口或切换到 1:1 原始尺寸；双击图片可以在适应窗口与 1:1 之间切换。
- 切换图片后再切回来，FloralMD 会恢复该图片先前的缩放比例与位置。
- 点击侧栏刷新按钮可重新扫描；新建或保存资源后也会自动刷新。
- 外部改名会尽量保持当前选择与展开目录；如果当前文件被删除或移出工作区，顶部会明确提示并停止向旧路径保存。
- 右键文件或文件夹可以在 Finder 中显示，或复制绝对路径。

切换资源前，FloralMD 会先保存尚未落盘的 Markdown；保存失败时会显示错误并保留当前内容。

## 管理工作区文件

- 侧栏顶部加号可在工作区根新建 Markdown 或文件夹；文件夹右键菜单可在该目录内新建。
- 文件或文件夹右键可重命名、制作副本、选择工作区内的目标文件夹移动，或移到系统废纸篓。
- 在侧栏内把项目拖到文件夹：默认移动，按住 Option 复制；拖到侧栏标题可把目标设为工作区根目录。不能把文件夹移入自身或子目录。
- 从 Finder 拖入侧栏文件夹或工作区标题会复制文件，默认和 Option 都不会搬走 Finder 原文件；同名项目不会被覆盖。把侧栏项目拖到 Finder 时使用标准 file URL，由 Finder 决定最终操作。
- 侧栏选中单个项目并保持键盘焦点后，可使用 `Command+X/C/V`、Return 重命名、Delete 移到废纸篓、Space Quick Look。焦点在 Markdown 编辑器时，这些键仍用于文本编辑，不会触发文件操作。
- 右键 Quick Look 和“在 Finder 中显示”同样适用于 FloralMD 不支持编辑的普通文件。
- FloralMD 不会覆盖同名项目；名称冲突、不可写目录或权限失败会取消操作并显示错误。
- 非空文件夹移到废纸篓前会明确确认。FloralMD 不提供永久删除。
- 当前 Markdown 或其父目录改名/移动前会先保存；成功后继续保存到新位置。
- 若操作会影响当前绘图，请先保存并切换到其他资源。文件服务不会猜测画布 dirty 状态。
- `.excalidraw` 与 SVG 是两个独立普通文件；重命名、复制、移动或删除其中一个，不会自动处理另一个。
- 本版本只完成单选操作，不提供批量选择或文件操作撤销。已知跨卷移动会明确拒绝；请先复制、核对副本，再自行把原文件移到废纸篓。

## 打开 Markdown 链接

- 实时编辑中按住 `Command` 点击相对 `.md`、`.markdown` 或 `.mdown` 链接；只读预览中直接点击。
- 工作区内目标会在当前窗口切换；`#fragment` 留在当前文档或目标文档内定位，不会启动另一个 FloralMD 窗口。
- 工作区外目标会沿用文件夹授权提示。请选择目标所在的准确文件夹；取消、缺失、目录、符号链接或保存失败都不会丢失当前文档。
- HTTP、HTTPS 和邮件链接继续交给系统；图片与绘图链接保持原来的打开方式。

## 创建与保存绘图

点击工具栏绘图按钮或使用 `Command+Shift+D` 新建绘图。完成后点击绘图工具栏的保存按钮或按 `Command+S`；首次保存时确认名称。

Draft 绘图的正式结构是：

- `drawings/<名称>.excalidraw`：可继续编辑且自包含原始图片的唯一事实源；
- `drawings/exports/<名称>.svg`：供 Markdown 引用的派生 SVG。

笔记局部 `drawings/` 和外部绘图目录使用同一规则：源文件保持原目录，SVG 位于同目录的 `exports/`。新保存不再创建或维护 `images/`。

在“设置 → 通用 → 绘图 SVG”选择自动同步方式：

- “仅 Draft 工作区”（默认、推荐）：Draft 保存时同步 SVG；外部绘图只保存 `.excalidraw`。
- “所有绘图”：外部绘图也同步到源文件父目录的 `exports/`。
- “从不”：自动保存不创建或更新 SVG。

无论选择哪一档，都可以点击绘图工具栏的导出按钮，或在命令面板搜索“导出绘图 SVG…”，手动选择 SVG 目标。目标已存在时，系统会先要求确认。

需要取出画布中某个图片元素最初插入的文件时，右键该图片并选择“导出原始图片…”。选择保存位置后，FloralMD 写出自包含源中的原始字节；画布上的裁剪、缩放和旋转不会烘焙进导出文件。取消保存不会创建文件，导出成功也不会改变绘图或 SVG。右键空白、形状或缺失原始文件的图片不会出现该菜单。

旧原型的 `excalidraw/`、`svg/`、`drawings/images/`、`notes/assets/drawings/`、`notes/assets/drawing-exports/` 与旧同级 SVG 不属于新写入结构。FloralMD 不会自动迁移或删除这些内容。

## 在 Markdown 中粘贴图片

在实时编辑模式把截图、剪贴板图片或 Finder 中复制的 PNG/JPEG/GIF/WebP/SVG 粘贴到光标处。

- Draft Markdown：图片保存到 `notes/assets/images/`。
- 外部 Markdown：图片保存到文档同级的 `assets/images/`。
- 剪贴板图片使用本地时间名，例如 `2026-08-12-09-35-21.png`；同一秒多张或已有同名时使用 `-2`、`-3`，不覆盖已有图片。
- 只有图片成功保存后，FloralMD 才插入相对 Markdown 链接。
- 一次粘贴多张图片时保持剪贴板顺序，并整体插入到按下 `Command+V` 时的选区；移动光标不会改变落点，一次撤销可整体撤销。

如果图片格式或数据无效，FloralMD 会显示错误并且不插入失效链接。

手写、粘贴或从侧栏插入的 PNG、JPG、JPEG、GIF、WebP 与 SVG 相对引用，会在 Markdown 实时编辑和只读预览中按当前 Markdown 所在目录解析；尚未保存的 Draft 文档按未来的 `notes/` 位置解析。实时编辑中，原始 `![](...)` 语法保持可见和可编辑，图片显示在源码行下方；改路径、粘贴、拖入、撤销/重做后会原位更新，不需要切换预览。应用内保存图片会自动刷新；图片由其他程序改写后，点击侧栏刷新按钮即可更新。中文、空格、括号、`#` 和 `%` 等路径字符需要使用标准 Markdown URL 编码。FloralMD 只读取当前工作区内的普通图片文件；缺失、目录、符号链接、伪装格式或越过工作区边界的路径会显示“Image unavailable”，但不会隐藏语法或阻止继续编辑。

## 从侧栏拖入已有资源引用

在 Markdown 的实时编辑模式中，从左侧统一工作区侧栏把文件拖到正文中的目标位置：

- PNG、JPG、JPEG、GIF、WebP、SVG 会插入图片语法，并继续引用原文件；
- Markdown 会优先使用 frontmatter 的 `title`，其次使用第一个标题，最后使用去扩展名文件名；
- `.excalidraw` 会引用其 SVG 导出物。先按当前同步规则在源文件父目录的 `exports/` 生成同名 SVG；
- 一次拖入多个文件时会按拖拽顺序逐行插入，并可一次撤销。

释放点可以映射到正文时，引用插入鼠标所在位置；即使当前另有非空选区，也不会误删该选区。只有释放点无法映射时，才按粘贴语义替换拖拽完成时的当前选区，不会追加到文末。

FloralMD 只插入相对引用，不会移动、复制、导入、改名或覆盖侧栏中的文件。目录和不支持类型不能拖入；预览、绘图与图片 Surface 也会显示不能放置的系统反馈。若绘图尚无 SVG，先保存并启用合适的 SVG 自动同步，或手动导出到上述标准位置后再拖入。

从 Finder 拖入文件时也使用相同规则：只有当前已授权工作区内的支持文件会生成一次相对引用；工作区外、目录、符号链接或不支持的文件会被拒绝，不会把绝对路径或裸文件名插入正文。

## 打开外部文件

从 Finder 打开支持的外部文件时，其所在文件夹成为临时工作区。首次访问同目录资源或写入图片时，FloralMD 可能要求授权该文件夹；请选择提示中同名的准确文件夹。

外部文件不会被搬入 Draft，FloralMD 也不会猜测更高层目录或创建隐藏项目文件。

## 打开工作区

在 File 菜单选择“打开工作区…”（`Control+Command+O`），也可在命令面板搜索同一命令，或使用空工作区中的按钮。选择后，整个文件夹就是该窗口的工作区根。

- 该操作不改变 Draft 默认位置，不复制或迁移文件。
- 当前窗口没有活动资源且没有未保存编辑时，会原位切换；否则新建独立窗口，当前内容保留不变。
- 同一工作区已在其他窗口中时，FloralMD 会激活该窗口。
- 取消文件夹面板不改变任何状态。书签失效、文件夹移动/删除或不可读时会明确报错，不会悄悄切回 Draft。

## 窗口工具

- `Command+Shift+P`：打开命令面板。
- Markdown 编辑或预览时，`Command +` 每次增大 1 pt，`Command -` 每次减小 1 pt，`Command 0` 恢复默认 15 pt；调整结果与设置中的基础字号同步，范围为 11–28 pt。
- 在命令面板搜索“打字机模式”可切换 Markdown 打字机模式；同一开关也位于“编辑”菜单和“设置 → 编辑”。
- 在命令面板搜索“SVG 自动同步”可进入对应设置；选中绘图时可搜索“导出绘图 SVG”。
- 置顶按钮：让统一窗口停留在当前 Space 上方；透明度由设置控制。
- 文件侧栏与 Markdown 大纲可以分别展开或收起。
- Finder 中选中 Markdown 并按空格，可以使用 FloralMD Quick Look 预览。

统一工作区支持的最小窗口内容尺寸是 `760×540`。缩小窗口时，FloralMD 会先临时收窄文件侧栏，并在 Markdown 大纲打开时把大纲一并计入可用宽度；不会缩小正文、画布或图片的字体比例。窗口重新放宽后，文件侧栏会恢复到用户此前拖动保存的宽度。

文件侧栏最窄为 180pt。若需要更多中央空间，可以手动收起文件侧栏或 Markdown 大纲；FloralMD 不会在用户未操作时自动覆盖其显示状态。侧栏标题过长时会从中间省略，但文件夹图标和标题起点保持可见。

## 数据安全说明

- FloralMD 不自动迁移或删除已有 Markdown、绘图、SVG 与图片。
- 新建与粘贴使用不覆盖命名；绘图保存只对本次计划涉及的自包含源和可选 SVG 执行暂存与失败回滚。
- 建议在首次使用该分支前备份重要工作区，并按 [PROGRESS.md](PROGRESS.md) 的人工验收清单检查。
