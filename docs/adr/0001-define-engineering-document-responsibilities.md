# 明确工程文档职责与决策记录边界

FloralMD 使用分工明确的文档体系：

| 文档 | 职责 |
| --- | --- |
| `CONTEXT.md` | 定义领域词汇 |
| `docs/PRODUCT.md` | 记录产品承诺与行为 |
| `docs/ARCHITECTURE.md` | 描述当前实现结构 |
| `docs/PROGRESS.md` | 记录完成状态与验证证据 |
| `docs/adr/*.md` | 保存重要决定及其理由 |
| `.scratch/*` | 保存具体工作的规格与工单 |

- 允许这些文档为保持各自完整性而出现受控重叠。
- 后续 agent 在相关工作前必须读取领域词汇与相关 ADR。
- 只有难以逆转、缺少背景会令人困惑、并且来自真实权衡的决定才进入 ADR；小型或临时决定留在对应的产品文档、规格或工单中。
