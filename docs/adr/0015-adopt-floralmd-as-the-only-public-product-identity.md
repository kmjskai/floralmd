# Adopt FloralMD as the only public product identity

The maintained macOS implementation continues from the accepted local-workspace editor line, while FloralMD becomes its only public product identity. The previous SlateMemo name is retained only in Git history and migration records; it is not a parallel product, bundle identity, update channel, support site, or public release line.

The existing FloralMD bundle identifier, public repository, release history, app icon, and Sparkle feed continue. The implementation does not restore the legacy Git panel, semantic minimap, native document tabs, or dual-sidebar architecture. Brand continuity and implementation continuity are separate concerns: the former follows FloralMD, while the latter follows the newer editor code.

The FloralMD iOS product line is outside this macOS repository migration.
